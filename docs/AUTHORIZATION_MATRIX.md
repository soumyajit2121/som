# Authorization matrix

Legend: ✅ allowed · ❌ denied · ◐ restricted (see notes). "DB" = enforced by RLS/trigger in Postgres; "Srv" = enforced in server action/route; "UI" = hidden/disabled in UI. Every rule below is enforced in **all three** layers unless noted.

Account states: `pending` (signed up, not approved), `active`, `inactive` (deactivated). Pending and inactive users can read only their own profile and see the approval/deactivated screen.

| Resource / action                                                           | Admin                                     | Teammate                                                                                                    | Pending / inactive   | Anonymous | Enforcement / test                                                                                                                                                 |
| --------------------------------------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Read tournaments, enrolments, teams, squads, venues, opponents              | ✅                                        | ✅                                                                                                          | ❌                   | ❌        | RLS `*_read` → `app.is_active()`; test "pending user can read no team information"                                                                                 |
| Create/edit/archive/delete tournaments, enrolments                          | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS `*_admin_write`; test "teammate cannot create, edit or delete tournaments"                                                                                     |
| Delete tournament that has matches                                          | ❌ (archive)                              | ❌                                                                                                          | ❌                   | ❌        | FK `ON DELETE RESTRICT` + server check; test "cannot be deleted"                                                                                                   |
| Create/manage teams, squads (memberships)                                   | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS; test "teammate cannot manage team membership"                                                                                                                 |
| Create/edit venues and real opponents                                       | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS; test "teammates cannot create real opponents"                                                                                                                 |
| Create dummy opponent                                                       | ✅                                        | ✅                                                                                                          | ❌                   | ❌        | RPC `create_dummy_opponent` checks `is_active()`; direct insert with `is_dummy` blocked by trigger                                                                 |
| Read matches and participant names/statuses                                 | ✅                                        | ✅                                                                                                          | ❌                   | ❌        | RLS                                                                                                                                                                |
| Create match                                                                | ✅                                        | ◐ own team only, `created_by = self`, status draft/scheduled, auto-included as Confirmed                    | ❌                   | ❌        | RLS `matches_insert`, trigger `matches_before_write`, `matches_after_insert_add_creator`, deferred `matches_creator_participant`; tests "teammate-created matches" |
| Edit match                                                                  | ✅ all fields                             | ◐ creator only: title, date, times, venue, notes, CricHeroes URL; not after In Progress/Completed/Cancelled | ❌                   | ❌        | RLS `matches_update` + trigger `FORBIDDEN_FIELD`; test "creator can edit basic details but not..."                                                                 |
| Replace dummy opponent                                                      | ✅ (audited as `match.opponent_replaced`) | ❌                                                                                                          | ❌                   | ❌        | trigger; test "replacing a dummy opponent is recorded"                                                                                                             |
| Cancel / restore match                                                      | ✅                                        | ❌ (ask an admin)                                                                                           | ❌                   | ❌        | trigger (status change forbidden)                                                                                                                                  |
| Delete match                                                                | ✅                                        | ◐ creator, before any other player is attached, not completed                                               | ❌                   | ❌        | RLS `matches_delete`; test "creator can delete their match only until..."                                                                                          |
| Override duplicate warning (`allow_duplicate`)                              | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | trigger; test "warns about duplicate matches..."                                                                                                                   |
| Set own participation (Not Responded/Available/Maybe/Unavailable/Confirmed) | ✅                                        | ✅ (own team's matches; not on completed/cancelled)                                                         | ❌                   | ❌        | RLS + trigger; test "teammate can update their own availability"                                                                                                   |
| Set Playing (final XI)                                                      | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | trigger; test "cannot select themselves into the playing XI"                                                                                                       |
| Change another player's participation                                       | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS + trigger + API 403; tests (DB + E2E direct API)                                                                                                               |
| Add / remove other players                                                  | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS; tests "cannot add/remove another player"                                                                                                                      |
| Remove self from a match                                                    | ✅                                        | ◐ yes, except the creator of that match                                                                     | ❌                   | ❌        | trigger `CREATOR_MUST_PARTICIPATE`; test                                                                                                                           |
| Edit own profile (display name, phone)                                      | ✅                                        | ✅                                                                                                          | ◐ pending: name only | ❌        | RLS `profiles_update_self`; test "update only their own profile"                                                                                                   |
| Edit another user's profile                                                 | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RLS                                                                                                                                                                |
| Change role / status (approve, promote, deactivate)                         | ✅ (not last admin; admin must be active) | ❌ (incl. self)                                                                                             | ❌                   | ❌        | trigger `FORBIDDEN_FIELD`, `LAST_ADMIN`, `ADMIN_MUST_BE_ACTIVE`; tests                                                                                             |
| Read email/phone (`profile_private`)                                        | ✅                                        | own only                                                                                                    | own only             | ❌        | RLS; test "cannot read other players' phone numbers"                                                                                                               |
| Push subscriptions                                                          | own only                                  | own only                                                                                                    | ❌                   | ❌        | RLS `push_subscriptions_owner` (admins can't read endpoints); test                                                                                                 |
| Notification preferences                                                    | own (read all)                            | own                                                                                                         | ❌                   | ❌        | RLS                                                                                                                                                                |
| Read notifications                                                          | own + all (admin view)                    | own                                                                                                         | ❌                   | ❌        | RLS; test                                                                                                                                                          |
| Mark notification read/unread                                               | own                                       | own                                                                                                         | ❌                   | ❌        | column grant `update(read_at)` only; test "may only change the read marker"                                                                                        |
| Create notifications                                                        | via triggers/RPC                          | via triggers/RPC                                                                                            | ❌                   | ❌        | no insert grant for `authenticated`; test "cannot forge notifications"                                                                                             |
| Post general announcement                                                   | ✅                                        | ❌                                                                                                          | ❌                   | ❌        | RPC checks `is_admin()`; test                                                                                                                                      |
| Delivery records, reminder ledger                                           | ✅ read                                   | ❌                                                                                                          | ❌                   | ❌        | RLS admin read; no write grants                                                                                                                                    |
| Audit history                                                               | ✅ read                                   | ❌                                                                                                          | ❌                   | ❌        | RLS admin read; no write grants for anyone (trigger inserts)                                                                                                       |
| Scheduler RPCs (`record_reminder`, `claim_push_deliveries`)                 | ❌ (service role only)                    | ❌                                                                                                          | ❌                   | ❌        | `revoke execute`; test "cannot call scheduler functions"                                                                                                           |
| `/api/cron/reminders`                                                       | Bearer `CRON_SECRET` only                 | ❌                                                                                                          | ❌                   | ❌        | timing-safe compare; E2E 401 test                                                                                                                                  |
